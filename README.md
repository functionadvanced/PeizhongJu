# PeizhongJu
My homepage. View at https://functionadvanced.github.io/PeizhongJu/

Machine Learning topic pages live in `research/` and share `assets/site.css` with
the homepage. Update introductions and publication memberships in
`assets/research-topic-content.json`, then run `python3 scripts/build-topic-pages.py`
to refresh the static pages from the citations in `index.html`.

Editable `.drawio` system diagrams and their SVG/PNG exports are kept as source
assets in `assets/research-diagrams/`.
